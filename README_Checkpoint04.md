# BASSLINE 구현 체크포인트 04

2026-09-19 · Unity 6000.6.0f1 · URP 17.6.0 · TestOnly / FunctionalProxy

생활·조사 기능에 **실제 이동과 접촉으로 발생하는 사건 시험 씬**을 추가했습니다. 본편 완성본이 아니라, Source FixtureK의 접촉 사건 일부를 플레이하고 검증하는 개발 중간본입니다.

## 실행

Windows ZIP의 폴더 전체를 풀고 `BASSLINE_FixtureK.exe`를 실행하세요. Windows의 맑은 고딕을 사용하며 OS 글꼴 파일을 재배포하지 않습니다.

- **Shift+F1**: 기존 생활 시험 씬. 대화·약속·물건 전달·관찰·노트.
- **Shift+F2**: Main Hall 보행 및 아트 검토.
- **Shift+F3**: 새 사건 시험 씬 `FixtureK_Incident`.

씬 전환은 새 세션입니다. 필요한 진행은 먼저 F5로 저장하세요. 생활과 사건 시험 씬은 저장 위치가 별도입니다.

| 입력 | 기능 |
| --- | --- |
| 마우스 이동 | 우클릭 없이 시점 회전 |
| WASD | 이동 |
| E | 물건 줍기·문 열기·대화·기록 장치/흔적/쓰러진 인물 조사 |
| R | 가까운 대상의 자세한 행동 메뉴 |
| G | 물건 내려놓기 |
| N / M | 세계를 정지하는 NOTE / 마지막 확인 위치 지도 |
| Esc | 뒤로 또는 일시정지, 커서 해제 |
| F5 / F9 | 현재 시험 씬 세션 저장 / 복구 |
| Tab / Enter | 화면 버튼 탐색 / 선택 |

## 새 사건 씬에서 확인할 흐름

1. 14:59 도서실에서 시작합니다. 알려진 시설 도면은 N → 지도에 있습니다. 도서실 북쪽 출구에서 복도를 따라 동쪽 홀로 이동합니다. 홀 북쪽에서 북쪽 우회 복도를 따라 동쪽으로 가면 작업실 북문이 나옵니다.
2. 도윤은 15:01부터 실제로 작업실로 이동합니다. 도구를 보고 손에 들고, 대상과 접촉 가능한 조건이 유지될 때만 사건이 진행됩니다. 정상 시험 조건의 접촉은 15:02:05, 지연된 쓰러짐은 15:02:10입니다. 방해하면 이 시각대로 강제 실행하지 않습니다.
3. 개입을 시험하려면 먼저 작업실의 **O31**을 E로 가져가세요. 가상의 X31 시험 도구이며 실제 위해 방법이나 재료는 구현하지 않았습니다. 도구가 없으면 원래 접촉 사건은 성립하지 않습니다. 게임은 이를 “살인 예방 성공”이라고 알려 주지 않습니다.
4. 현장에 도착하면 쓰러진 진우를 바라보고 E로 상태를 살펴볼 수 있습니다. 현재 상태를 봤다는 기록이며 가해자·발생 시각·의학적 사망 판정으로 확대하지 않습니다.
5. 빈손으로 가까운 서윤에게 E를 눌러 본인이 실제로 목격한 내용을 들으세요. 관측이 벽 등에 가려졌다면 그 사건 증언을 생성하지 않습니다. 다른 인물에게 같은 내용을 자동 복사하지 않습니다.
6. 작업실의 **V1 기록 열람 장치**와 **P31 접촉 흔적**을 가까이에서 바라보고 E로 조사하세요. 조사에는 2초가 걸리며 거리·시야를 벗어나면 취소됩니다. V1은 처음부터 설치된 카메라가 실제로 본 기록만 제공합니다. P31에는 행위자의 이름이 없습니다.
7. NOTE → 사건/기록에서 받은 자료의 지지 범위와 한계를 읽고 가설을 정리합니다. 같은 V1을 반복 열람하거나 전해 들어도 독립된 출처가 늘어나지 않습니다.
8. 사건 대기·접촉·지연 결과·조사 도중 F5/F9를 사용합니다. 사건 상태와 목격, 기록, 인물의 몸/시선 방향, 중첩 NOTE와 조사 진행을 복구합니다.

사건 저장: `Application.persistentDataPath/TestOnly/FixtureK_Incident/session-slot-v1.dat`. 생활 저장: `TestOnly/FixtureK/session-slot-v1.dat`. 다른 시험 씬의 파일은 불러오지 않습니다. `.previous`에 이전 유효 저장을 보존합니다.
