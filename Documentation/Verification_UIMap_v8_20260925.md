# v8 대화·지도 첫 개선 검증

## 적용 범위

사용자 영상의 인물/대사 중심 구성을 참고해 기본 대화 버튼을 6개에서 3개로 줄였다. 선택지와 기록 전송 미리보기는 같은 화면에서 펼친다. 기존 사건, 기록 열람, 실제 거리·시야 제약을 유지한다.

지도는 관측 좌표를 비스듬하게 투영하는 입체 보기와 평면 보기를 제공한다. 장소 표식에 이름을 붙이고, 직접 통과한 층 연결을 양쪽 층에 표시한다. 본인의 위치·방향은 별도의 자기 위치 조회를 사용하며, 아직 내부를 확인하지 않은 공간이나 다른 층에는 자기 표식을 표시하지 않는다. 다른 사람의 실시간 위치, 미확인 방 윤곽, 모르는 연결은 전달하지 않는다.

입체 도식의 개선이며 실제 저택 모델/조명 개편은 아직 아니다. 완성된 3D 도면 또는 최종 아트로 세지 않는다.

## 자동 검사

- `BL22_UiMap_v8.xml`: 4개 중 2개 통과. 대화/복수 신고는 통과했으나 새 지도 도형의 CanvasRenderer 누락으로 지도 두 검사가 실패했다.
- `BL22_UiMap_v8b.xml`: 해당 구성 요소를 명시한 뒤 지도/대화 3/3 통과. 다른 층의 자기 표식 비노출, 수신한 층 연결만 표시, 지도 조작의 기억·시선 불변, 기록 전달 미리보기의 비전송, Esc/기록/탐색 복귀를 확인했다.
- `BL22_EditMode_v8b.xml`: 전체 122/122 통과. 공개 사망 추가 공표의 한 번 연장과 두 사건 전말 공개/한 명 판정도 포함한다.

- `BL22_PlayMode_v8.xml`: 48/48 통과(1,800.0초). 최종 상반신 표시·배경 대비 조절 코드가 포함된 소스로 실행했다.
- Windows v8 첫 빌드: 오류 0/경고 2, 57.8초. `BL22_Smoke_v8/mansion-smoke.json`은 28장, 오류 0, 사용자 설정 복원, 프로세스 종료를 확인했다. 기본/선택지/전송 미리보기와 지도 표식을 직접 살펴봤다. 이 첫 검수 뒤 인물 상반신 확대·배경 대비·중복 익명 장소 번호·대기 종료 알림의 대화 덮어쓰기 방지를 조정했다.

최종 v8c에서는 기록 전달 미리보기를 넓은 대사 영역으로 옮기고 즉시 전부 표시했다. 우측에는 기록 번호·출처·전송 안내만 남겼다. `BL22_features_v8c.xml`의 집중 검사 11/11이 통과했다(43.0초). 이 마지막 화면 배치 수정 후 전체 48개 검사를 다시 실행한 것은 아니며, 사건·저장 로직 변경은 없다.

Windows v8c 빌드는 성공했다(오류 0/경고 2, 42.9초). `BL22_build_v8c.txt`와 로그에 결과를 보존했다. `BL22_Smoke_v8c/mansion-smoke.json`은 `PASS_SMOKE_ONLY`, 28장, 런타임 오류 0, 사용자 설정 복원 성공이다. 실행 ID는 `20260925T130322370Z`이며 검사 프로세스 종료를 확인했다. 720p/1080p·125% UI의 최종 기록 미리보기 두 장과 기본 대화 720p를 직접 살펴봐 제목·본문·출처·버튼이 겹치지 않음을 확인했다. v8b에서 기본 대화/선택지/지도도 직접 검토했다.

창 검수는 실제 입력 장치 전체를 자동 조작하는 시험이 아니라 기존 버튼 이벤트를 실행하고 렌더링한 화면을 확인하는 범위다. 두 추가 대화 메뉴 캡처에서는 시험용 세계 진행을 잠시 고정했다. 이를 자연스러운 대화 지속 시간/동선 검증으로 세지 않는다. 실제 저택과 3D 인물은 여전히 임시 형태이며 가시성 개편을 계속해야 한다.
