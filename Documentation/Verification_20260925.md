v3 전체 실행에서는 살아 있는 17명 모두 소집 안내를 받았고 유스티도 재판장에 도착했으나, CH_15가 대계단 위 도착점을 향하면서 바닥층에 머물렀다. 주민도 높이가 바뀌는 계단 구간에서는 평지용 측면 회피를 중단하도록 수정했다. 새 계단 검사는 단독 승강·이동 중 목적지 변경 및 저장/로드·임시 장애물이 사라진 뒤 통과를 검사하며 수정 전에도 통과했다. 따라서 이 검사만으로 전체 실패의 원인을 확정하거나 해결했다고 주장하지 않는다. 첫 계단 시험의 IndexOutOfRange는 진단 문자열의 테스트 코드 오류였고 수정했다. v4 전체 검증에는 CH_15의 실제 계단 진입 저장 상태와 위치 추적을 추가했다. 새 전체 결과가 있어야 소집 문제 해결 여부를 판단할 수 있다.

Windows 검사에서는 실제 제목 버튼으로 탐색에 들어가 캐릭터 컨트롤러로 15.4m 이동했다. 실제 설정 버튼으로 125% 화면 크기를 적용하고, 1280×720과 1920×1080에서 제목/탐색/설정/노트/지도/지난 기록/대화를 캡처했다. 노트 중 시간이 멈추는지, 지도와 지난 기록 열람이 새 개인 기억을 주지 않는지, 실제로 가까이 다가간 인물의 대사를 수신하는지 확인했다. 대화 캡처 전 플레이어의 위치를 잡는 부분은 명시적인 TestOnly 배치이며 자연스러운 전체 동선 검증으로 세지 않는다. 사용자 설정은 검사 뒤 복원했고 창도 종료했다.

처음 창을 숨겨 실행한 D3D12/D3D11 시도는 검은 화면으로 화면 캡처 검사가 실패했다. 사용자에게 창 표시 승인을 받은 뒤 보이는 창에서 같은 실행본으로 화면 검사에 통과했다. 숨긴 실행 결과를 통과로 수정하지 않았다.

화면은 글자·버튼·동작 확인 범위다. 인물과 환경은 아직 임시 형태이며, 전체 게임의 최종 아트/재미/장시간 성능 검증을 뜻하지 않는다. 기록된 6초 단위 프레임 수치도 전체 성능 벤치마크가 아니다.
