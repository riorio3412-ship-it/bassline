## BASSLINE 적용 작업

1. 대화에서 다음 대사를 읽는 기본 입력을 명확히 하고, 큰 여섯 버튼 상시 노출을 줄인다. 질문·약속·기록 전달은 해당 행동을 선택할 때만 펼친다. 대화 기록과 자동 읽기는 작고 일관된 위치로 모은다. 마우스/키보드 조작이 서로 다른 화면 깊이를 요구하지 않아야 한다.
2. 조사에서는 가까이 보고 있는 대상과 지금 가능한 한두 행동을 먼저 보여준다. 노트로 이동한 뒤 다시 현장을 찾느라 같은 조작을 반복하는 부분을 줄인다.
3. 재판에서는 현재 화자와 선택한 주장·근거를 한 흐름에서 보존한다. 비교법을 선택하려고 화면을 여러 번 오가는 부담을 줄이고, 제출과 뒤로 가기가 일관되게 동작하도록 한다. 정답 자동 노출/자동 제출을 추가하지 않는다.
4. 지도는 입체적인 층 분리, 계단·출입구·방과 통로의 연결, 현재 위치/방향을 우선한다. 높은 층이 아래층을 가리지 않게 선택 층 강조·분리 보기를 검토한다. 모르는 방이나 보이지 않는 NPC의 현재 위치를 지도로 새로 알려주지 않는다.
5. 실제 저택도 비슷한 회색 통로가 반복되는 상태를 개선한다. 공간별 색/재질/조명, 교차로의 표식, 중요한 계단과 문 주변의 형태 차이로 방향을 기억할 수 있게 한다. 이동·충돌·기존 저장 배치와 연결된 변경으로 검증한다.

작화는 사용자가 채택한 CH04 간결화 v6 방향을 유지한다. 한국어는 짧고 자연스럽게 쓰되 인물별 말투를 지키며, 모든 인물이 같은 유행어나 농담을 반복하지 않는다.

## v8 첫 적용

- 대화 기본 화면은 선택지·대화 기록·종료의 세 버튼. 질문·약속·기록 전달은 선택지를 펼치면 나온다. 대사 클릭/상호작용 키로 글자를 펼치고, 전부 읽었으면 선택지를 연다. 대화 기록은 기존 노트 일시정지를 유지한다. Esc는 선택지를 먼저 접고 그다음 대화를 닫는다.
- 기록은 내용을 보고 직접 전송한다. 기록 전달 메뉴를 여는 것만으로 최근 기록을 상대에게 보내지 않는다. v8c는 미리보기 본문을 넓은 대사 영역에 즉시 표시하고, 출처와 기록 번호를 별도로 보인다. 채택한 스탠딩 원본 파일은 그대로 두고 상반신을 더 크게 표시하며 배경 대비를 낮췄다.
- 지도는 입체/평면 전환, 읽은 장소 이름, 층간 통과 연결, 내 위치·시선 방향, 내 위치로 돌아오기를 지원한다. 사람 표식은 여전히 마지막 관측이다. 입체 표식은 관측 지점의 도식이며 실제 방 윤곽·크기를 뜻하지 않는다.
- UI 표시는 uGUI의 기존 화면을 수정했다. 새로운 장면·방 경계·출입구 정보를 지도에 넣지 않았다. 실제 저택의 재질·조명·입체 건축 요소는 다음 작업이며 이번 변경에 포함되지 않았다.
