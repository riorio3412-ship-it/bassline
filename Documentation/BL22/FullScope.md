# BASSLINE v2.2 전체 구현 추적

상태는 실제 코드·콘텐츠에 대한 보수적 중간 평가다. `partial`은 전체 항목 통과를 의미하지 않는다. 과거 테스트는 해당 당시 범위에만 적용한다.

## 원문과 검증

원문 147쪽을 SourcePages.json에 페이지별로 보존했다. Requirements.json에는 원문 SHA-256과 번호가 명시된 인수 항목 109개를 연결했다. 페이지가 추출됐다는 사실은 구현·검증 완료를 뜻하지 않는다.

다음 사용자 피드백은 명세보다 우선한다: 대화·노트는 내부 자료 구조나 추론 상태를 조작하는 메뉴로 만들지 않는다. 자연스러운 질문, 시간순 대화, 설명을 읽을 수 있는 명시적 정보 전달 흐름을 사용한다.

최종 모델·스탠딩·환경 완성도와 UI 편의성은 개수·자동 테스트와 별도로 실제 화면에서 검토한다. 현재 절차 생성 모델과 일부 초상화는 그 최종 기준을 충족하지 않는다.

0.11의 대화·노트 개편과 검증 범위는 Iteration_011.md에 기록했다. 다음 제작에서는 본편 자율 사건, 전체 장 규칙, 생활 콘텐츠, 최종 모델과 환경을 함께 계속 진행한다. UI 역시 남은 설정·재판·장시간 사용 흐름과 150% 가독성 검토가 필요하다.

0.12에서 펜의 대여·실제 소지 이전·직접 반환·거절·중단·저장 복원을 연결했다. IG01의 공용 반납/수거/오해 정정과 3변형은 미완료다. 소품 경로와 소지는 검증했으나 팔·손 접촉 연출은 임시여서 다음 그래픽 작업 대상으로 유지한다. 권태겸의 신규 2D 스탠딩을 연결했다. 세부 증거는 Iteration_012.md에 남긴다.

0.13에서 절차 생성 인물의 어깨·팔꿈치·손목과 플레이어 팔을 연결하고, 충돌을 확인하는 접근→양손 접촉→소지 이전→손 거두기를 구현했다. 접촉과 뼈 길이, 접근/접촉 중 저장 복원 검사 증거는 Iteration_013.md에 남긴다. 최종 인물 조형이나 공통/고유 애니메이션 전체 완료는 아니며 MODELS/ANIMATION의 잠정 상태를 유지한다.

0.14에서 권태겸의 얼굴·가르마·안경·정장 메시를 교체하고 나머지 일반 인물의 캡슐 앞머리를 우선 개선했다. 실제 3D 렌더의 변경 반영 오류도 수정했다. Iteration_014.md에 조형 검토와 게임 내 검증 범위를 기록한다. 최종 19인 모델로 완료 처리하지 않으며 전체 범위와 UI·그래픽의 지속적인 개선을 유지한다.

0.15에서 IG01의 공용 반납대→민서의 실제 수거·운반→공용 정리함→장부 작성/열람→원물 회수·직접 반환을 본편에 연결했다. Iteration_015.md에 저장과 개인 지식, 물리 이동 검증의 한계를 기록한다. 사적 메모 변형·주장 정정·학습 결과가 남으므로 IG01의 세 조건이나 12문법/36조합을 완료로 세지 않는다.
0.16에서 실제 플레이어 발화, 청취자별 오해와 정정, 민서의 거절·사과에 대한 관계 반응, 공용 장부와 원물 확인을 통한 설명을 연결했다. Iteration_016.md에 검증 범위를 기록한다. 사적 메모 변형과 학습·보상 원장이 남아 IG01 전체나 36개 조합을 완료로 세지 않는다.


0.17에서 임민서의 개별 작업복·얼굴·머리·손목시계·보온병 3D 외형과 2D 스탠딩을 연결했다. 실제 어깨 위치를 고려한 공용 반납대 접근으로 변경했다. Iteration_017.md 및 Art_Minseo_017.md에 원전, 실제 렌더와 동작 검증 범위를 기록한다. Humanoid/얼굴 리그·LOD·최종 텍스처 등은 남아 MODELS의 provisional_geometry 및 전체 요구 수량을 유지한다.

0.18에서 태겸의 개인 가방/메모, 실제 읽기 뒤 의미를 묻는 대화, 가방 앞 놓기와 회수, 실제 반환/정정을 근거로 한 1회 학습 기록과 10 EXP를 연결했다. Iteration_018.md에 저장 실패 복구와 보상 중복 방지 검증을 남긴다. IG01 전체 200 EXP와 스킬 해금 또는 생활 의뢰 전체 완료를 뜻하지 않는다.

0.19에서 김진우의 설정과 어긋난 2D를 흰 곱슬머리·버건디 카디건 스탠딩으로 교체하고 163cm 개별 3D 외형을 연결했다. Iteration_019.md와 Art_Jinwoo_019.md에 실제 메시/화면 검토 및 남은 품질 차이를 기록한다. 그래픽과 UI는 사용자의 추가 지적이 없어도 계속 개선해야 할 작업 범위다. MODELS/ANIMATION의 provisional_geometry와 STANDING/UI의 partial 상태를 유지한다.

0.20에서 김진우의 갈라진 소매를 관절을 따라 변형하는 연속 메시로 바꾸고, 얼굴·의복에서 떠 보이는 선과 바지의 카디건 관통을 수정했다. 옷 전용 중간 관절은 물리 도달/소지 판정에 참여하지 않는다. Iteration_020.md에 변형·원격 자세 비노출·실제 화면 검증을 기록한다. Humanoid 전체 리그, 얼굴 표현과 최종 조형·질감은 아직 남아 있으며 19인 모델이나 94종 애니메이션을 완료 처리하지 않는다.

0.21에서 즉시 확정되던 약속을 실제 제안→답변 발화로 바꾸고, 직접 고르는 장소 목록·중단 후 다시 묻기·개인 수신 원문/시각·저장 검증을 연결했다. 실제 NPC 경로 이동과 미수신 확정 방지를 검사했다. Iteration_021.md에 증거와 한계를 기록한다. 사적 초대장 수정/미수신의 IG02 전체 사건과 3개 조합, 구체적인 대체 제안과 같은 약속 수정 UI는 미완료다. 전체 목표와 모든 기존 요구 수량/상태는 유지한다.

0.22에서 도서관의 실제 약속 카드 쓰기·사적 장소/시각 변경·개인별 수신 원문/시각·전달 발화·답변·중단/저장 복원과 구버전의 빈 카드 추가를 구현했다. 관련 82개 검사 및 보강한 실제 접근 검사 6개 재통과, Windows 빌드와 두 해상도 74개 네이티브 화면 검토를 완료했다. Iteration_022.md에 범위와 증거를 기록한다. 자율 NPC의 IG02 사건·다른 참가자의 독립 원문/목격·오해/재협상·3개 조합과 종이 필기 표현/필기 애니메이션은 미완료다. 모든 기존 요구 수량과 완료 상태는 유지한다.
