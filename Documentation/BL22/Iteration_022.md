# BASSLINE 0.22 작업 기록

약속의 장소나 시간을 종이에 고쳐 적고, 상대를 만나 말로 전하는 흐름을 연결했다. 통합 기획서 MAIN 69의 기존 레코드 확장과 MAIN 71의 IG02 ‘바뀐 약속’을 위한 작업이다. 사용자의 대화 단순화 요청에 따라 버전 번호나 수신 플래그를 조작하게 하지 않고 ‘약속 적기 → 장소 고르기 → 상대에게 이야기하기’로 표현한다.

## 플레이 흐름

원형 도서관의 독서 테이블에 약속 카드를 추가했다. 가까이에서 읽으면 종이에 적힌 내용을 볼 수 있다. 먼저 사람과 만날 약속을 정한 뒤 카드에 그대로 적거나 장소·시간을 고쳐 쓸 수 있다. 약속과 장소는 목록에서 직접 선택한다. 쓰기에는 실제 월드 시간 3초가 걸리며 이동하거나 취소하면 원래 내용이 유지된다.

고쳐 쓴 약속은 상대에게 자동으로 알려지지 않는다. 상대는 직접 받은 이전 시각·장소를 따라 움직인다. 다시 만나 ‘카드에 적은 약속 전하기’를 선택하면 민혁이 이야기하고 상대가 답한다. 말하는 도중 끊으면 종이 원문이 전달되지 않는다. 전달과 수락을 구분하며, 답을 받은 내용은 같은 대화 선택지에 계속 남기지 않는다. 카드를 읽고 선택하는 동안에는 생각할 시간을 주며 실제 쓰기·발화 때 월드가 진행된다.

## 상태와 저장

기존 SocialLedger의 약속을 수정 버전으로 확장한다. 참가자는 자신이 받은 버전만 알고, 받은 시각과 원문의 근원을 보존한다. 예전 약속에서 만났다고 새로 고친 약속까지 만난 것으로 처리하지 않으며 같은 약속의 관계 보상도 중복 지급하지 않는다.

카드 작성 중, 발화 중, 완료 뒤 저장을 이어갈 수 있다. 구버전 저장에는 로드 시점에 빈 카드만 추가하고 과거에 적거나 읽었다는 기록을 만들어 넣지 않는다. 실제 원문·작성 이벤트·내용·시각·전달 기록과 어긋나는 저장을 거절한다. 같은 내용을 다시 베껴 적을 때 이미 전달한 원문 참조를 바꾸지 않는다.

## 검증

최종 자동 검사, Windows 빌드 및 네이티브 화면 검토 결과를 아래에 기록한다. 네이티브 검토는 실제 충돌·거리 판정을 만족하는 위치에 플레이어를 배치한 뒤 실제 UI와 월드 틱을 실행하는 TestOnly 검사다. 자연스럽게 걸어 도달한 전체 플레이, 모든 사건 조합, 그래픽 완성도에 대한 최종 승인을 뜻하지 않는다.

## 남은 범위

이번 작업은 플레이어가 작성하는 카드와 변경 전달의 구현이다. NPC가 사적으로 초대장을 고치는 자율 사건, 다른 참가자의 독립 원문·장소 목격, 미수신 때문에 생긴 오해와 재협상·정정의 전체 연결, 서로 다른 조건의 IG02 3개 조합은 아직 완료하지 않았다. 카드의 현재 내용은 읽기 UI에서 확인하며 종이 표면의 실제 필기와 손의 필기 애니메이션도 남는다. 다른 인물 모델과 전체 UI·대사·사건·반복 플레이 수량은 기존 목표대로 계속 구현한다.

## 최종 검증

- PlayMode `BL22-v22-final1.xml`: 58/58 통과, 158.16초. 기존 관련 기능과 카드의 실제 이동·미수신·발화·저장·복원·원문 불일치 거절을 포함한다.
- EditMode `BL22-v22-domain-final.xml`: 24/24 통과, 0.18초. 개인별 버전과 수신 시각, 이전 만남과 새 약속의 분리 및 잘못된 기록을 확인한다.
- 실제 도서관 바닥·가구 충돌을 확인하는 카드 접근으로 검사 준비를 강화한 뒤 `BL22-v22-card-final.xml` 6/6 재통과, 38.73초. 앞의 58개와 중복되는 검사이므로 총 82개에 다시 더하지 않는다.
- Windows `BL22_v22_build3.log`: 성공, 오류 0, 기존 경고 4, 35.19초.
- 네이티브 `BL22-v22-smoke2`, RunId `20260925T222601716Z`: PASS_SMOKE_ONLY. 1280×720·1920×1080의 74개 화면, 런타임 오류 0. 빈 카드·장소 선택·작성 중·작성된 원문·변경 전달의 5단계가 추가됐다. 기존 대화·약속·노트·대여·반납·설정 복원도 확인했다.

첫 네이티브 실행은 도서관의 -2m 낮은 독서 공간을 검사 준비가 위층 높이로 접근해 실패했다. 실제 바닥 내비게이션 위치와 충돌·시야를 통과하는 접근으로 고쳤다. 카드도 폭 1m 책상의 가장자리 밖으로 걸치지 않도록 안쪽으로 옮겼다. 조작 가능 거리나 장애물 판정을 느슨하게 바꾸지 않았다.

이전 실행 환경에서 쓰기 권한과 Unity 라이선스 인식 때문에 중단됐던 빌드는 권한 복구 후 정상 완료됐다. 라이선스 설정이나 계정을 변경하지 않았다. 이전 소스 전용 전달본의 미빌드 상태는 위 최종 검증으로 갱신한다.

배포 폴더는 `outputs/BASSLINE_v0.22`이다. 이전 실행 파일은 보존한다. 배포 파일 SHA256 비교는 `Verification/BL22-v22-delivery.json`에 기록하며, 최종 소스도 다시 묶는다.
