# BASSLINE 0.19 작업 기록

MAIN 40쪽 김진우의 흰 곱슬머리·옅은 눈·버건디 카디건·163cm 설정에 맞춰 2D 기본 스탠딩과 개별 3D 외형을 연결했다. 기존 스탠딩 파일은 보존하며 대화 창에서 새 자산을 사용한다. 생성 원본, 프롬프트, 변경한 메시와 남은 제작 기준은 Art_Jinwoo_019.md에 기록한다.

카디건과 소매·손은 기존 실제 팔 리그를 따른다. 새로운 충돌체나 원격 상호작용 규칙은 추가하지 않았다. 정면·사선·측면·후면·얼굴을 Unity의 실제 메시로 렌더해 머리카락 반복과 신발 앞코의 관통을 수정했다. 씬 생성 버전을 019B로 갱신해 이전 외형이 생성 캐시 때문에 남지 않게 했다.

## 검사에서 발견한 문제

첫 관련 PlayMode 검사 BL22-v19-first.xml은 43개 중 42개 통과, 1개 실패했다. 머리카락을 포함한 실제 최고점이 1.64067459m로 163cm±1cm를 초과했다. 검사 허용치를 넓히지 않고 머리 자산의 높이를 조정했다. 발바닥 원점, 기존 물리 키, 팔 길이는 유지한다.

첫 Windows 빌드 BL22_v19_build1.log는 오류 0·경고 4로 성공했다. BL22-v19-smoke1은 54개 화면과 런타임 오류 0으로 새 3D/2D 연결 및 메모·대여·반납 흐름을 통과했다. 그러나 키 수정 전의 빌드이므로 최종 배포 근거와 구분한다. 최종 확인 결과는 아래에 추가한다.

## 검증 범위와 계속할 작업

Windows 화면 검사는 실제 플레이어 빌드의 720p/1080p, UI 크기 125%를 사용한다. 인물과의 근접 검사에서는 플레이어만 TestOnly 위치로 배치한 뒤 실제 가시선·발화 수신·버튼 흐름을 확인한다. NPC 순간이동이나 지식 주입은 없다. 숨긴 플레이어 창에서 캡처를 복구해야 할 때는 실제 URP 카메라/Canvas의 렌더 경로를 사용하며 자연 탐색이나 화면 FPS를 입증한 것으로 세지 않는다.

이번 버전은 아트가 완성되었다는 판정이 아니다. 현재 3D 얼굴·목/어깨 비율·관절 이음새·머리 질감은 제공된 컨셉아트보다 부족하다. 최종 얼굴/몸 리그, 의상 변형, LOD, 텍스처 아틀라스와 2D/3D 일치도를 계속 개선한다. UI도 지속적인 개선 범위에 포함되며 사용자에게 매번 지적을 요구하지 않는다. 전체 25개 작업군과 기획서 수량은 축소하거나 완료 처리하지 않는다.

## 최종 실행 확인

- `BL22-v19-final.xml`: 관련 PlayMode 검사 43/43 통과, 103.83초. 기존 대화/메모/대여/반납/저장 검사 40개와 스탠딩 관련 3개를 포함한다. 스탠딩 검사 중 2개는 기존 공유 텍스처 수명/원격 자세 비노출 검사이며, 새 1개는 김진우의 키·발바닥·외형 충돌체 부재·양팔 길이를 확인한다. 반복 실행한 검사를 새 검사로 더하지 않는다.
- `BL22_v19_build2.log`: 최종 Windows 빌드 성공, 오류 0, 경고 2, 16.20초. 경고는 기존 인물 UI의 deprecated FindObjectsSortMode/FindObjectsByType 사용에 관한 것으로 이번 외형 변경의 오류는 아니다.
- `BL22-v19-smoke2`, RunId `20260925T193511651Z`: PASS_SMOKE_ONLY. 1280×720·1920×1080 합계 54개 화면, 런타임 오류 0. 김진우 새 모델/스탠딩 연결, 개인 메모 경로, 대여/반납과 설정 복원을 확인했다. 720p 대화/메모, 1080p 새 대화를 직접 열어 글자·버튼·스탠딩의 잘림과 배경 투명도를 확인했다.

결과 실행 폴더는 outputs/BASSLINE_v0.19이며 이전 버전은 유지한다. 복사 파일 수와 SHA256 일치 여부는 Verification/BL22-v19-delivery.json에 기록한다. 이번 검증이 최종 아트 승인이나 전체 기획서 완료를 뜻하지 않는다.
