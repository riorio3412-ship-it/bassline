# 0.17 — 민서의 인물 외형과 손이 닿는 접근

직전 0.16은 실제 대화·정정·기록 개선을 검증된 실행 빌드로 전달한 진전이었다. 이번에는 전체 기획 목표를 유지하면서 공통 임시 인형이던 임민서의 개별 외형을 제작했다.

## 달라진 점

182cm의 큰 체격, 바랜 작업 셔츠, 손목시계와 보온병이라는 원전의 특징을 3D 모델에 반영했다. 얼굴과 짧은 머리, 셔츠 깃·가슴 주머니·접은 소매, 작업 바지와 작업화를 개별 메시로 만들었다. 손바닥과 손가락도 이어지는 형태로 다듬었다. 같은 옷과 소품을 가진 새 2D 스탠딩을 대화 화면에 연결했다. 이미지의 원본 투명도를 유지한다. 자세한 원전·자산·생성 프롬프트는 `Art_Minseo_017.md`에 기록했다.

기존 이동·관측·소지·충돌 주체는 유지한다. 시계는 왼쪽 손목을 따르는 외형이며 보온병은 오른쪽 허리의 외형 소품이다. 이 둘의 시간 확인·물 마시기 기능까지 구현했다는 의미는 아니다.

## 검증에서 발견한 문제와 수정

- 정면 렌더에서 겉셔츠가 티셔츠를 관통했다. 실제로 앞이 열린 겉셔츠로 바꾸었다. 이후 게임의 사선 화면에서 평면 티셔츠 옆으로 배경이 보이는 것을 확인해 안쪽 티셔츠도 입체 몸통으로 만들었다.
- 초기 PlayMode 검사 `BL22-v17-playmode.xml`은 34개 중 31개 통과, 3개 실패였다. 어깨 폭을 넓힌 민서가 기존의 가슴 중심 접근 방식으로는 반납대에 닿지 못해 수거·보관 및 설명 경로가 실패했다. 라이선스 경고가 CLI 요약에 함께 나왔지만 XML이 증명하는 실패 원인은 실제 검사 실패다.
- 접근 방향을 현재 오른쪽 어깨 위치에서 계산하도록 수정했다. 몸을 돌리고 실제 CharacterController로 접근한다. 팔 길이를 늘리거나 충돌을 무시하지 않는다. 새 모델의 높이·발바닥 원점·추가 충돌체 부재와 실제 정리 중 손목시계·팔 길이를 확인하는 검사 2개도 추가했다.

## 검증 범위

첫 Windows 검사 `BL22-v17-smoke1`(20260925T182815622Z)은 56개 캡처, 런타임 오류 0, 새 민서 모델·스탠딩 연결, 대화·대여·반환과 설정 복원을 확인했다. 이 검사는 플레이어를 검사 위치에 배치한 화면 검증이며, 앞의 별도 수거 동작 실패를 대신 통과시켜 주지 않는다. 최종 수정 후 결과는 아래에 별도로 기록한다.

최종 모델 19명·전체 스탠딩·Humanoid 및 얼굴 리그·LOD·텍스처·전체 생활과 사건 콘텐츠·릴리스 기준은 아직 미완료다. 이번 모델도 최종 아트로 완료 처리하지 않는다.

## 최종 동작 확인

어깨 정렬 수정 후 `BL22-v17-reach.xml`에서 앞서 실패한 수거·운반·공개 근거 설명 3개가 통과했다. 이후 최신 코드와 모델로 `BL22-v17-final.xml`을 실행해 34/34 통과(84.66초)를 확인했다. 기존 대여·실제 전달·공용 정리·대화·선택지·이전 저장 검사 32개와 새 모델/리그 검사 2개다. 3개의 재검사와 중복 합산하지 않는다. 실제 모델의 발바닥 원점·182cm 높이 오차 1cm 이내, 외형의 추가 충돌체 부재, 수거·운반 중 시계 부착과 팔 길이 유지가 이 결과에 포함된다.

3D 최종 조형 검토는 ArtV17의 정면·사선·옆·뒤·얼굴·시계 렌더다. 원본 소스 해시와 실제 메시 목록은 render-source.txt에 보존했다. 이미지만 새로 그려 3D 모델인 것처럼 표시한 것이 아니라 게임과 같은 Unity 메시를 카메라로 렌더했다. 다만 최종 아트 품질이나 완성된 Humanoid 리깅의 증거는 아니다.
