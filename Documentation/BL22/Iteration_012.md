# 0.12 — 생활 행동: 펜 대여와 반환

2026-09-26. 전체 게임 제작의 중간 단계. 직전 목표 턴은 대화 UI 수정·회귀 검사·실행 빌드 배포로 실제 진전이 있었다. 이번에는 통합 기획서 14–15쪽의 생활/개인 지식 원칙, 71–72쪽의 IG01/TEST-LIFE01을 출발점으로 정상 플레이의 물건 대여 기반을 연결했다.

## 실제로 연결한 플레이

권태겸에게 말을 걸어 ‘다른 이야기 → 물건 이야기’에서 펜을 빌려도 되는지 묻는다. 허락을 끝까지 들은 뒤 ‘펜 받기’를 누르면 이미 존재하던 펜이 이동한다. 빈손 여부를 확인하고, 양쪽 사람의 상태·거리와 소품 이동 경로의 고체 차폐를 매 틱 재검사한다.

전달은 120틱이며 90틱에 소지가 원자적으로 바뀐다. 그 전 취소는 원 소지자, 이후 취소는 새 소지자를 유지한다. 취소로 물건이나 대여 기록이 복제되지 않는다. 노트를 열면 동작이 정지하고 닫으면 이어진다. 실제 세계의 다른 인물과 시간은 동작 중 계속 진행한다.

‘어디에 돌려주면 돼?’라고 물어 반환 지시를 들을 수 있다. 태겸에게 직접 돌려주면 대여 종료와 관계 경험이 남는다. 바닥에 내려놓거나 멀리서 반환을 요청하는 것은 반환 완료가 아니다. 손이 차 있으면 실제 거절 대사를 듣는다. 허락을 듣다 중단하면 ‘받기’ 권한이 생기지 않는다.

전달을 직접 수행한 두 사람과 처음부터 끝까지 관측한 주변 인물만 전달 기록을 얻는다. 멀리 있는 NPC에게 사건 기록을 방송하지 않는다. 소지와 소유권·절도 의도는 구분한다. 펜의 공개 이름은 외관인 ‘흠집 난 푸른 펜’이며 소유자를 미리 답으로 표시하지 않는다.

## 저장과 아트

발화와 별도로 전달 커서·확정 여부·이전 NPC 활동·대여 원문 참조·반환 여부를 저장한다. 허락 원문과 실제 소지/전달 사건이 어긋난 저장은 적용 전에 거부한다. 0.11 저장에는 새 펜을 불러온 시점의 콘텐츠 추가로 등록하고 과거 대여 사실을 만들지 않는다. 다음 장의 대여 상태는 유지하고 새 루프에서는 초기 상태로 돌아간다.

3D 펜은 푸른 몸통, 뚜껑, 은색 클립, 마모 흔적으로 제작했다. 가까이서 살펴본 기록은 현재 외관만 말한다. 권태겸의 새 2D 스탠딩은 기획서 P06의 가르마·안경·가방을 반영해 내장 image_gen으로 제작하고 CH_06 리소스에 연결했다. 이전 미채택 시안은 보존했다. 최종 사용자 승인으로 기록하지 않는다.

## 남은 범위와 다음 작업

이번 구현은 IG01 전체 완료가 아니다. 공용 반납대에 잘못 둔 펜, 민서의 실제 수거·서랍 보관, 독립 수거 기록, 잘못된 주장 정정, 세 가지 문법 조건 조합까지 구현해야 한다. 이 대여를 12문법/36조합 또는 36개 생활 의뢰의 완성 수량에 포함하지 않는다. 본편 살인 사건은 여전히 비활성이고 X31 테스트 사건을 본편으로 승격하지 않았다.

현재 전달은 경로 검사를 수행하는 소품 동작이다. 3D 팔·손 리깅과 쥐는 자세는 미완성으로, 소품이 인물의 임시 손 메시와 시각적으로 떨어져 보인다. 최종 접촉 애니메이션으로 간주하지 않는다. 다음 작업에서 실제 손 위치·팔 동작과 모델/스탠딩 일치를 먼저 개선하고, 반납대와 수거 행동을 연결한다. 모든 물건의 Rigidbody·마찰·낙하·파손·사후 이력 구현도 별도 미완료다.

전체 최종 목표와 나머지 범위는 FullScope.md 및 원문 147쪽/명시 인수 항목 109개를 유지한다.

## 최종 실행 화면 확인

BL22_v12_build3.log의 Windows 빌드가 성공했다(오류 0, 경고 4). 최종 BL22-v12-smoke2의 실행 ID는 20260925T153859860Z이며, PASS_SMOKE_ONLY / 화면 42장 / 런타임 오류 0 / LoanExchangeVerified=true / ControlsPreferencesRestored=true를 확인했다.

1280×720, UI 125%의 최종 대여 화면을 직접 확인했다. 새 권태겸 스탠딩과 두 줄 허락 대사가 표시되고 선택지가 서로 겹치지 않는다. 반환 후 노트에서는 전달 장소가 중앙 홀로 표시되고 ‘태겸에게 펜을 돌려줬어요.’로 상태가 갱신된다. 다만 일반 물건 위치 관측은 아직 ‘미확인 장소’로 남는 항목이 있어, 전달 기록과 별개인 RoomAt 높이 판정을 추가로 고쳐야 한다. 임시 3D 인물과 스탠딩의 외형 차이도 남아 있다.

이 검사는 가까운 대화 위치를 테스트 전용으로 배치한 뒤 실제 발화·버튼 이벤트·전달 틱을 실행했다. 숨겨진 플레이어 창에서는 SRP 카메라/캔버스 캡처 보조 경로를 사용했다. 자연 이동으로 만나는 전체 생활 사건, 네이티브 입력, 성능 또는 전체 게임 완료의 증거로 간주하지 않는다.
