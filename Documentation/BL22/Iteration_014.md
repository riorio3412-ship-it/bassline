# 0.14 — 인물 조형 교체의 첫 단계

2026-09-26. 0.13에서 확인한 캡슐 앞머리와 임시 정장 실루엣을 개선했다. 전체 제작 범위를 유지한다. 사용자에게 UI·그래픽·대사·조작감을 스스로 점검하고 계속 개선하며, 현재 빌드를 최종 품질로 삼지 않는다고 답했다.

## 실제 변경

권태겸의 머리·얼굴·재킷·셔츠·칼라·라펠·바지·구두를 별도 메시로 작성했다. 눈꺼풀·눈썹·얇은 금속 안경을 추가하고, 대칭 가르마를 곡선형 머리 덩어리로 만들었다. 나머지 일반 인물도 세로로 과하게 늘어난 캡슐 앞머리를 곡선 메시로 교체했다. 개인별 최종 헤어스타일 완료는 아니다.

기존 어깨·팔꿈치·손목·그립 구조에 새 소매를 연결했다. 손가락·전달 동작·충돌 캡슐과 개인 관측 규칙은 기존 구조를 사용한다. 정적 메시와 움직이는 팔·다리는 구분한다. 유스티와 플레이어의 최종 전신 모델은 이번 변경 대상이 아니다.

실제 3D 메시의 정면·사선·측면·후면·얼굴을 별도 조명에서 렌더하는 편집기 검토 도구를 만들었다. 이 이미지는 게임 플레이 장면, 최종 모델 승인 또는 새 2D 스탠딩이 아니다. 생성 소스의 SHA256, UTC 시각, 메시 정점 수와 경계를 함께 저장한다.

## 작업 중 발견한 문제

첫 실행은 배치 모드에서 저장되지 않은 기본 장면에 추가 장면을 열어 실패했다. 배치 모드에서는 단일 장면으로 열도록 고쳤다. 이전 메시를 CopySerialized로 덮어쓴 직후 렌더했을 때 변경 전 이미지가 다시 출력되는 것도 실제 PNG 해시로 확인했다. 정점·삼각형·노멀·경계를 Mesh API로 다시 설정하도록 변경한 뒤 다른 이미지가 출력되는 것을 확인했다. 첫 캡처의 회색 머티리얼 문제는 동기 셰이더 컴파일과 캡처 전 렌더를 적용한 뒤 색이 표시되는 것으로 확인했다.

실제 렌더를 보고 긴 목의 노출, 둥글게 솟은 어깨, 코·안경의 두께, 셔츠·재킷과 뒤쪽 바지의 겹침, 두피 안으로 들어간 뒷머리의 반경을 차례로 조정했다. 중간 실패 로그와 초기 리뷰 이미지는 보존한다.

## 미완료 범위

현재도 교체 가능한 중간 모델이다. 2D 작화와 맞는 세밀한 얼굴·머리 실루엣, 표정 리깅, 부드러운 관절 변형과 의상 주름, 손의 자연스러운 형태, 직업 소품의 실제 소지/행동 연결을 계속 제작해야 한다. 다른 인물의 얼굴과 의상, 19인 전체 모델, 94개 애니메이션 완료로 세지 않는다.

IG01 공용 반납대·민서의 수거·오해 정정, 사건과 생활 콘텐츠, UI 4해상도/150% 가독성, 최종 환경과 릴리스 검증도 기존 범위에 남는다. MODELS와 ANIMATION은 provisional_geometry 상태를 유지한다.
