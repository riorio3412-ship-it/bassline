# 0.11 — 대화와 노트 사용성 개편

2026-09-26. 전체 v2.2 구현의 중간 작업 기록이며, 최종 완성 또는 출시 판정이 아니다.

## 플레이어에게 달라진 점

- 대화를 열면 질문을 바로 고른다. 안부, 좋아하는 것, 다른 이야기, 대화 다시 보기, 대화 끝내기가 기본 메뉴다.
- 예전의 분류 순환과 한 건씩 넘기는 기록 대신, 대화와 관찰 내용을 시간순으로 읽는다.
- 다른 사람에게 이야기를 전할 때는 문장을 목록에서 선택하고, 내용을 읽은 후 명시적으로 말한다. 미리보기와 취소는 정보를 전달하지 않는다.
- 사건 관련 도구는 사건 수첩으로 모았다. 일반 대화에서 가설·유보·철회를 조작할 필요가 없다.
- E 또는 대사 클릭으로 끝까지 듣는다. 대사가 끝난 뒤에는 시간이 멈추므로 질문을 천천히 고를 수 있다.
- 다른 인물이 앞을 지나가 시야를 가려도 들리는 대화는 계속된다. 실제 벽이나 거리 때문에 목소리가 끊기면 들은 부분만 남긴다.
- 긴 목록에는 스크롤바, 마우스 휠, Page Up/Down과 키보드 선택을 연결했다.

## 내부 동작과 수정

NPC 인사·일상 대화·목격 답변에 발화 진행 상태를 도입했다. 미리 준비된 전체 문장을 개인 지식으로 즉시 전달하지 않고, 실제 발화와 각 청자의 수신 범위를 계산한다. 늦게 온 청자는 앞부분을 얻지 않는다. 빠르게 듣기도 원래 세계의 모든 틱을 처리한다. 중단·저장·불러오기 시 발화 커서와 들은 부분을 복원한다.

프로필은 3D 모델을 정적인 중립 자세로 보여준다. 멀리 있는 실제 인물의 현재 자세·사망·소지 상태를 프로필이 노출하지 않도록 분리했다. 대화에는 2D 스탠딩을 유지한다. 모델 자체는 아직 임시 지오메트리다.

재판 시작 때 기존 대화와 읽기 정지 토큰을 정리한다. 다음 장으로 전환한 뒤 저장을 불러올 때 선택한 장 규칙이 누락되던 optional bit도 수정했다.

이 화면 검사는 실제 CharacterController 이동 후 대화 촬영 위치를 TestOnly로 배치하고, Unity 버튼 이벤트를 호출한다. 재판 화면도 명시적인 테스트 자료를 사용한다. 숨겨진 창의 검은 스왑체인 대신 SRP 카메라·Canvas 렌더 요청으로 촬영한 경우 그 방법을 보고서에 기록한다. 따라서 OS 키보드·마우스 전체 사용성, 정상 본편의 사건 해결, 전체 경로 및 성능 기준 통과를 의미하지 않는다.

이전 smoke1과 smoke3에서 실패한 이유와 로그도 보존한다. smoke1은 인물 콜라이더가 음성을 차단한 문제, smoke3은 별도의 HUD 상호작용 시야 검사로 대화가 종료된 문제다. 둘 다 수정했으며, 후자는 실제 HUD 업데이트를 포함한 회귀 검사로 재현했다.

## 남아 있는 전체 범위

전체 원문 147쪽과 번호가 명시된 인수 항목 109개를 SourcePages.json / Requirements.json으로 추적한다. 추출과 등록 자체가 구현 완료를 뜻하지 않는다.

일반 본편의 자율 사건은 아직 활성화하지 않았다. 테스트 전용 사건과 재판 화면 검사는 본편 전체 진행의 증거가 아니다. 20개 장 규칙 중 실제 효과 연결은 2개이며, 최종 3D 모델·리깅·애니메이션·환경 아트·대사 전체 분량·생활 콘텐츠도 계속 제작해야 한다.

플레이어의 정보 전달·약속 명령 및 모든 공적 안내가 아직 위 발화 시스템으로 전환된 것은 아니다. 음성 경로는 고체 차폐를 확인하지만 완전한 RoomPortal 감쇠 모델은 아니다. UI 4해상도·150%, 배포용 한국어 글꼴, 릴리스 빌드 정보 차단, 클린 PC 및 8시간 안정성 검사는 미완료다.

다음 개선 기준은 FullScope.md에 유지한다. 현재 빌드의 실행 성공을 UI·그래픽·시스템 개선의 종료 기준으로 삼지 않는다.
