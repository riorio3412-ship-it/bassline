# 구현 경계와 확장 지침

기준은 대화에서 전달된 최신 BASSLINE 명세와 첨부 18인 기획서입니다. 첨부 문서의 개발 제안은 참고 데이터로 읽었으며, 고정 첫 범인 예시는 일반 회차의 고정 범인으로 사용하지 않았습니다. 모든 참가자는 20세입니다.

## 상태의 소유권

`WorldState`만 현재 게임 상태를 소유합니다. Unity 오브젝트는 화면을 나타내는 프록시이며 캐릭터의 진실을 저장하지 않습니다. 문을 조사하면 `WorldSimulation.Move`가 실제 방 연결을 확인하고, 로그와 소지품 위치를 갱신합니다. 표시된 3D 방은 변경된 방 상태에서 재생성됩니다.

`CharacterData`는 변하지 않는 기획 정보입니다. `CharacterState`는 회차 내 지식, 방향별 관계, 위치, 압박, 가설과 공개 입장을 보유합니다. 회차 초기화 때 새 상태를 만들고 과거 재판 보관함만 이어 붙입니다.

`Incident.culprit`와 실제 스냅샷은 생성기·검증기·정산기만 해석합니다. `ReasoningSystem`은 확인한 증거 ID에서 출발합니다. 새 NPC 기능을 추가할 때 범인 ID와 비교해 정답률을 조절하면 안 됩니다. 테스트에서 실제 범인 ID만 바꾸고 NPC의 판단이 변하지 않는지를 확인합니다.

## 사건 생성

일상 행동으로 다음 조건을 갖춘 기회를 찾습니다.

1. 압박이 충분히 누적된 NPC가 인장을 실제로 보관한다.
2. 현재 방의 동석자 전원과 갈등 이력이 있고, 피해자 상한을 넘지 않는다.
3. 협력 성향에 따라 고백·화해로 사건을 회피할 수도 있다.
4. 적합한 틀에서 현재 위치, 아이템 이력, 갈등 이벤트를 참조해 진실과 증거를 만든다.
5. 최소 인원·각각의 추리 경로·접근성·출처·시간표를 통과한 뒤에만 사건을 확정한다. 실패 시 임시 이벤트를 롤백한다.

두 틀은 물건의 원래 소유자와 사건 시각의 보관자가 같은지에 따라 나뉩니다. 현재 추리 퍼즐은 의도적으로 좁은 범위입니다. 장소·사람·동기를 달리하는 것과 서로 다른 논리 구조를 만드는 것은 별개의 다양성이며, 후자를 충분히 구현한 상태라고 주장하지 않습니다.

현재 시각 인증 기록은 신뢰 가능한 시설이 특정 시각의 현장 밖 위치를 보증하는 임시 장치입니다. 현실적인 알리바이 오차·이동 시간의 범위·시설의 부분 관찰을 확장할 때에는 단순 ID 배제 집합 대신 시간 구간 제약을 도입해야 합니다. 물증 경로 역시 다른 사건에서 항상 인장만 반복하지 않도록 별도 템플릿과 독립 출처가 필요합니다.

## 재판과 지식

개인 진술은 참이거나 거짓일 수 있으며, 공유해도 확인된 공식 사실로 바뀌지 않습니다. 원본을 조사하거나 검증된 원본을 공개하면 실제 지식이 확장됩니다. 단서의 요구 관계를 확보해야만 배제 효과가 작동하므로 인장 소지 사실 하나만으로 범인을 결론 내리지 않습니다.

`DialogueDirector`는 발언 수 36회, 동일 발언 키, 화자 순환, 직전 발언에 대한 방어·중재 반응을 관리합니다. 감정 폭발의 캐릭터별 전용 시나리오는 아직 없습니다. 능력치 중 관찰은 조사 성공 기회, 침착은 방어 표현, 공감은 중재와 보호 투표에 쓰고, 논변·추론의 정교한 효과는 향후 확장 대상으로 남겨두었습니다. 능력치가 정답을 만들어 내지는 않습니다.

투표는 증거로 세운 가설과 분리된 단계입니다. 미완성 정보에서의 관계 편향, 공개 지지 약속, 친구 보호, 자기 생존이 표에 영향을 줄 수 있습니다. 이유는 `Ballot.reason`에 남습니다. 기본 게임 화면은 익명 득표만 보여 주고 A9에서만 익명 이유를 추가 공개합니다. 내부 디버깅과 공개 UI를 구별합니다.

## 규칙

`Content.json`의 `implemented`가 참인 후보만 뽑습니다. 타입 가중치를 먼저 뽑은 뒤 그 타입 내부의 규칙을 뽑으므로, 규칙 개수가 많은 타입이 의도치 않게 유리해지지 않습니다. 중대 두 개·동일 유형·직전 규칙·인원 조건을 제외합니다. 데이터만 등록한 규칙을 작동한다고 표시하지 않습니다.

신규 제안은 전부 비활성입니다. 특히 B11은 기존 B8과 중복됩니다. 기존 A8은 의심표 공개이며 A11의 임시 피고 지정은 실제 피고 절차가 있어야 구분됩니다. B12와 B4는 정보 차단 범위와 조사 합류 시점을 먼저 확정해야 합니다.

## 생존자 경계

6명 이하에서 피해자 한 명으로 제한합니다. 5인 사건 오답에서 무고자 추가 퇴장을 유예합니다. A1은 무고자를 중복 퇴장시키지 않습니다. 4명에서 일반 사건 생성은 중단하고 별도의 임시 심리를 거칩니다. 정상 회차는 정확히 3명에서 반복합니다. 플레이어 퇴장은 정상 3인 루프와 별도로 새 회차 재시작을 제안합니다.

정식 최종 심리는 아직 집필되지 않았습니다. 현재 자발적 계약 포기 심리는 연결 상태와 기록 보존을 검사하기 위한 임시 시나리오이며, 원문의 계약 위반 심리와 다릅니다. 허위 위반으로 임의 추방하지 않기 위한 의도적인 미완성 지점입니다.

## 저장과 실행 검증

파일은 버전 번호 1, 전체 상태와 난수 상태를 담습니다. 임시 파일을 쓴 뒤 기존 파일을 원자적으로 교체하고 백업합니다. 현재 캐릭터·방 수 검사는 기본 방어만 제공하므로 이전 버전의 구조 변경에는 명시적인 마이그레이션이 필요합니다.

`Tests/`는 Unity 비의존 핵심 로직을 .NET에서 실행합니다. Unity DLL 참조 컴파일은 Unity API 사용의 형식을 확인할 뿐, 실제 엔진 실행·GUI·물리·글꼴 검증을 대체하지 않습니다. 현 환경의 Unity 라이선스 클라이언트 IPC 연결이 거부되어 해당 실행 검증과 Windows 배포 빌드는 미완료입니다.
