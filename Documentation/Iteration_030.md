# BASSLINE v0.30 — 무기 흔적과 실제 세척

이번 변경은 v0.29 이후의 사건 후 물리 상태 연결이다. 전체 게임 완성을 뜻하지 않는다.

- 실제로 성립한 주인공의 무기 타격에서만 무기의 금속 부분에 붉은 얼룩이 남는다. 빗나감, 원인 미성립, 예전 저장의 과거 공격에는 흔적을 소급 생성하지 않는다.
- 손에 든 물건을 살펴보면 현재의 얼룩을 짧은 문장으로 기록한다. 색만으로 성분, 피해자, 사용자, 범인, 발생 시각을 알아내지 않는다.
- 주방 수도에 가까이 가서 E로 손에 든 무기를 씻는다. 손과 무기는 충돌을 확인하며 물 아래로 이동한다. 움직이기·내려놓기·다른 상호작용은 중단한다. 동작 중에는 진행률을 보여준다.
- 세척은 얼룩을 줄여 잔여 자국을 남긴다. 실제로 계속 지켜본 사람에게만 씻는 행동의 관측이 생긴다. 세척 자체를 살인이나 은폐 의도의 증거로 승격하지 않는다.
- 세척 전 기록은 유지한다. 전후 표면 관측은 같은 물건에서 나온 자료이므로 별개의 독립 근거로 늘리지 않는다.
- 중간 동작·완료 이력·흔적이 저장된다. 같은 루프의 다음 장에도 물리 상태를 보존하고 새 루프에서 초기화한다. 기존 저장에는 현재부터 수집하도록 이행한다.

구현 기본값: 세척 180틱(3초), 150틱에 실제 물 세척 완료, 이후 손 회수. 얼룩/물/수도/손 모션은 임시 표현이며 최종 아트가 아니다. 시신·바닥의 혈흔, 성분 검사, NPC 범행 계획, 완성된 은폐 전략은 이번 변경에 포함하지 않았다. 세 무기에 공통 코드가 적용되지만 실제 실행 확인의 타격·세척 대상은 주방 칼이다.

두 PDF의 실제 인과, 변화 후 기존 관측 보존, 세계 결과의 장간 유지, 인지 범위와 공정성 규칙을 따른다. 주인공 살인 가능 지시는 유지한다. NPC 카메라는 추가하지 않았고 신들의 눈을 사건 증거로 쓰지 않는다.

다음 핵심: 제작된 본편 NPC 사건과 개인 동기, 실제 준비·행동, 카메라 없는 독립 책임 근거 두 경로, 자연 발견·조사·재판 연결. 무기 얼룩만으로 이 공정성 조건이 완성된 것으로 취급하지 않는다. 기존 시험용 X31을 정상 사건으로 승격하지 않는다.

확인 범위: 새 도메인 테스트 WeaponResidueTests 3/3 통과(Verification/v030-weapon-residue.xml). 최종 실행본 Logs/v030-build-04.log 성공, 오류 0 / 경고 15, 25.7373858초. 마지막 안내 문구 수정까지 포함한다.
