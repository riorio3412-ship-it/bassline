구버전 자료 `Verification/BL22_legacy_v6_fullflow.json`은 19:50에 끝난 v5 전체 시험의 실제 최종 저장을 보존한 것이다. v6b와 같은 단일 사건 저장 형식이며, v7 전체 시험이 새 결과로 덮어쓰기 전에 복사했다. 새 원장을 만드는 과정에서 지난 기록이나 개인 지식 ID, 세계 시각, 챕터를 잃지 않는지 확인했다.

Unity의 inline null 처리에 맞춰 기존 `OptionalObjects`의 bit 16으로 챕터 원장 존재를 표시한다. 이전 파일은 실제 이벤트로 재구성하고, 새 파일은 저장된 원장을 검증한다. 다음 챕터 저장도 이 표시를 유지한다. 실패한 v7c 로그를 통과로 바꾸지 않았다.

전체 PlayMode v7 뒤에 이전 저장 이력 대조와 존재 표시 수정이 들어갔다. 그 최종 변경은 집중 PlayMode v7d와 EditMode v7d로 검증했다. 전체 긴 시험을 최종 코드에서 다시 실행했다고 기록하지 않는다.

작업 폴더의 복수 사건 모음/추가 공표 일정 초안은 .NET 도메인 검사 22개를 통과했다. 아직 Unity 런타임·UI·저장에 통합하지 않았으며 위 실행본 범위에 포함되지 않는다. 해당 초안으로 본편 복수 사건을 완성했다고 주장하지 않는다.
