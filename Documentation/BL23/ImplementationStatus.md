## 게임 흐름 (씬 연결 + 실플레이 점검 완료)
타이틀 → 새 게임/이어하기/불러오기/설정 → 프롤로그(유스티 연설, 3D 궤도 카메라) → 일상(1·3인칭, 대화, 수첩 9탭, 지도, 기다리기/수면) → 사건(자율 NPC 계획·실행) → 시신 발견 방송 → 수사(검시 카드, 흔적, 증언, 시간선) → 소집 → 심판(TM01–08, FOCUS, 반박/동의/출처 질문/지목, 최종 재구성, 최종 변론, 투표·사망자 탭) → 판결(처형/탈출 연출) → **3D 전말 재생**(실제 녹화 프레임 + 원장 자막) → 다음 챕터 → 루프 종료/재생성.

## 알려진 한계 / 미완
- 캐릭터: GLB 3인(민혁·진우·도윤)은 제공 모델 기반으로 완성도가 높고, 절차 생성 16인은 개성은 뚜렷하나 머리카락 형태가 단순(헬멧형)하고 손가락 관절이 없다. 진우 GLB는 흰 머리·흰 코트(제공 모델 그대로).
- 원문 "12문법 × 조건 3 = 36 검증 조합"은 시스템은 갖췄으나 36개 조합을 개별 플레이 검증하지 않았다.
- 파편 합치기/수리(AT-022), 해상도·UI 150% 점검(AT-064), 8시간 연속 실행(AT-069), 클린 PC 배포 검증(AT-070) 미실시.
- v0.31 저장 이관(AT-066): 구조가 달라 이관 불가 — 발견 시 보존만 하고 안내(현재 PC에는 v0.31 저장 없음).
