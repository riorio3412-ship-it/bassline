## 2. 메인 세션용 요약 — 일상·NPC 동기·증거 제시 (구현하지 않음, 기획서 발췌)

### 2-1. 일상 활동 (MAIN 2.4·2.8, v1.1 05·05-1·06-2, MAIN 11.7–11.8)
- 활동은 **목표 선택→준비→이동→자리 확보→준비 동작→실행→반응→마무리**의 단계로 보여야 한다(도착만으로 끝나지 않음). 활동별 소품·시간: 식사 10–20분(식판·좌석), 물 20–60초(컵/보온병), 수면 6–8시간, 짧은 휴식 5–20분, 독서 10–40분(책갈피), 게임 5–20분, 수리·공예 10–45분(빌린 도구), 대화 1–8분, 산책·탐험 5–30분. 중단 시 남는 상태(먹은 양, 책갈피, 작업 단계)를 보존.
- 효용 점수: 필요 0–4 + 취향 0–3 + 약속 6 + 개인 목적 0–4 + 관계 −3~3 − 이동 0–3 − 반복 0–2, 30초마다 재평가, 3점 이상 좋아야 전환(무한 재계획 방지). 같은 방 6명이 같은 활동을 복제하지 않을 것.
- 평온한 날 콘텐츠: 인물별 2–4일 장기 목표 2개 이상(지도 제작·작은 공연·물건 복원·게임 대회·온실 정리·공동 기록·갈등 중재), 실제 단계 수행으로 진척. 생활 요청 36종(대여·전달·공동 작업·취미 모임·탐험·중재 각 6)과 각 3결과(성공·거절·중단).
- 회차 생활 조건(11.7): 루프마다 중심 생활 조건 1개(복원 준비·공동 지도·작은 전시회·개인 작업의 날·공동 정리·새 구역 탐방) + 보조 0–1개. 참여를 강제하지 않음.
- 공동 프로젝트(11.8)는 저택을 실제로 바꾼다(지도 Revision, 운반 동선, 전시품 위치, 온실의 젖은 표면·운반 흔적, 게임 모임 참가 기록, 공용 물품 대조).
- 작은 사건(11.11): 다른 곳 반납·늦은 일정 전달·"작업 완료"의 말 차이·반복된 소문 — 살인 신호로 쓰지 않는다.

### 2-2. NPC 동기와 목표 — 왜 그곳으로 가는가 (MAIN 2.4–2.5, 3.1, 11.9, v1.1 05·05-2·05-4·07)
- 후보 우선순위: **안전 대응 → 수락한 시간 약속 → 긴급 피로·생리 → 개인 목표 → 관계 행동 → 취향 휴식**. 계획 변경마다 지각한 원인이 있어야 한다.
- 관계는 방향별 신뢰·호감(−100~100) + 두려움·원한·존경·경계·빚·애착 태그(원인 이벤트 포함). 약속 이행 +3 신뢰, 확인된 거짓말 −5, 즐거운 공동 경험 +1.
- 약속은 제안→수락→변경→확정→진행→완료/불참/취소, 3분 불참 뒤 대기·연락·다른 활동.
- 만남의 조합(11.9): 같은 방에 있다고 친구가 되지 않는다 — **목적이 겹칠 때** 공동 작업·대여·대화 제안. 플레이어 습관 반응은 현재 루프에서 본 행동만.
- 살인 의도: 압박 인지 → 대안 비교(도움·고백·협력·회피·포기가 먼저) → 의도 → 계획 → 준비 → 접근 → 기회 재검사(이동 시작·문 통과·물건 확보·원인 직전·결과 직전) → 실행. 무산된 계획을 다른 피해자에게 자동 이전하지 않는다. "살인이 아직 없어서"는 원인이 아니다.
- 시선(05-4): 위험 → 새 소리·급접근 → 대화 상대 → 사용 물체 → 관심 인물 → 목적지 순, 0.8–3초 유지 후 분산.
- 복도·문(05-3): 2m 앞 감속·우측 양보, 좁은 문은 통행 토큰, 5초 막히면 말로 요청·10초면 우회.

### 2-3. 증거·시간선 제시 (MAIN 3.4·3.6·4.4 UI05–UI07, v1.1 10-2·10-4·10-6)
- **질문 먼저**: 관찰 후 알려진 범위에서 큰 질문 2–4개("발견 장소와 원인 장소는 같은가", "그 소리는 누가 냈는가", "기록은 어느 문을 보장하는가"). 이동 흔적이 없으면 "누가 옮겼는가"를 먼저 보이지 않는다. 조사거리(Lead)는 증거가 아니라 방법(장소·증언·기록·동선 측정).
- 관측 단계: Basic(시야)·Close(접근)·Detail(20–60초)·Compare(비교, 정지).
- 증거 카드: 이름, 획득 방식, 관측 시각 범위, 장소, 원본/사본, 보존 상태, 출처, **"알 수 있는 것/아직 모르는 것"**. 기술 ID는 숨김.
- 노트 탭: 질문 / 증거 / 시간선 / 인물 / 지도 / 약속 / 이전 루프. 목록 28% · 선택 자료 44% · 연결·출처 28%. 기본은 목록형, 자유 보드는 추가 보기.
- 연결 작업: 질문 선택 → 알려진 자료 1–4개 → 규칙(시간·경로·물체·범위·출처·인과) → 결론 미리보기 → 기록. 후보는 공통 속성으로 최대 8개, **정답 조합만 빛나게 하지 않는다**.
- 시간선(UI06): 인물별 행, 직접 목격 실선·전언 점선·추정 빗금·계획 테두리, 오차는 폭 있는 띠, 같은 사람의 겹침은 "범인"이 아니라 "검토할 겹침".
- 재구성: 알려진 방·통로만, 가정에는 "가정" 라벨, 결과 5종(Possible / PossibleWithAssumption / Contradicted / ImpossibleUnderKnownState / InsufficientInformation).
- 숨은 수치·거짓말 확률·유죄 확률·**남은 미발견 증거 개수는 어느 화면에도 표시하지 않는다**.
- 재판(UI07): 3D 재판장·현재 화자·대사·짧은 논점만, F를 눌렀을 때만 검증 가능한 주장 강조, 결과는 "근거와 범위"를 먼저("북문 밖 출입은 이 기록에 포함되지 않습니다").
- 피드백 문구 예: "이 기록은 15:10 이후입니다…", "두 진술은 같은 목격에서 나왔습니다…", "옷차림은 비슷하지만 얼굴은 확인되지 않았습니다".
- 이번 작업과의 접점: 각 살해 방법의 핵심 단서는 2~3장으로 설계했다(1-5절). 노트 UI가 사건별로 "시신·현장 흔적·물건" 카드를 먼저 묶어 보여 주면 가독성이 가장 크게 좋아진다.
