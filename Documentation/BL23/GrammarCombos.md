# 원문 12문법 × 3조건 = 36 검증 조합 (AT-051)

원문 부록 F의 IG01–12를 BL23 커널의 실제 시스템으로 구현했다. 아래 조합은 **대본이 아니라 서로 다른 실제 조건**이며, 무작위 헤드리스 캠페인에서 각 조합의 상태·원장 서명이 실제로 관측되는지를 `SimTests census`로 센다(`Tests/BL23/SimTests/Census.cs`).

- 관측 = 해당 조건이 자율 시뮬레이션에서 실제로 일어남(누가 설계해 넣은 사건이 아님).
- 조합별 **독립 조사 경로**(원문: 최소 2개, 하나는 특정 NPC 생존·호감·권능에 의존하지 않음)를 함께 적는다.
